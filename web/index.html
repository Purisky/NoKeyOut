open-source standalone key box

A small box that locks API key access with a physical switch.

Standalone hardware and a physical switch block accidental or malicious agent access to API keys.

Screen needs http:// — browsers block WebAssembly from file://.

01

Three things the box does

Keys on the box
Provider keys live only on the device. Clients get gateway keys, revocable per machine.
Physical lock
The switch closes SSH and the panel.
Local screen
240x240: IP, lock state, usage, quota.
02
