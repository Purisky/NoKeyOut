# 开放式框架（六角铜柱版）

只保留"固定主板 + 固定屏幕 + 固定开关"三件事，没有壳体、没有盖板。

## 结构

一件打印件（L 形）：

| 部位 | 作用 |
|---|---|
| 底板 58 × 68 × 3 | 四个 Ø3.4 孔，孔距 42.2 × 42.2 → M3 铜柱 + 主板 |
| 前立板 3.4 × 35 高 | 28.6 视窗 + 4 个 M2 螺柱 → 屏幕（44 × 32） |
| 前立板左侧 | 6.5 × 3.4 滑槽 + 12.4 × 6.4 压配腔 → 拨动开关（12×6×6） |

主板中心在原点；屏幕整体在主板前缘之前 1.2mm，两者在 Z 上不重叠。
开关在 y −37…−25，位于主板轮廓之外，不占板上空间。

## BOM

| 件 | 数量 | 说明 |
|---|---|---|
| 打印框架 | 1 | 17.1 cm³，无支撑 |
| M3 六角铜柱 | 4 | 母-母，10mm（板底 z 13） |
| M3×6 螺丝 | 8 | 4 颗从底板下进铜柱，4 颗穿主板进铜柱上端 |
| M2×4 自攻 | 4 | 屏幕四角 → 立板螺柱（Ø1.6 底孔 2.6 深） |
| 拨动开关 | 1 | 压进腔体，X 向 0.1 过盈 |

## 打印

* 底板贴床，前立板是一面竖直墙 → **不需要支撑**；屏幕螺柱是水平小圆柱，自支撑。
* 3 圈壁、4 层顶底、15% 填充即可；立板 35mm 高，建议 PETG。

## 装配

1. 4 颗 M3×6 从底板下方穿入，拧进铜柱下端。
2. 屏幕 4 角 M2×4 拧进立板背面螺柱（框架平放，螺丝刀竖直）。
3. 主板套上 4 根铜柱，M3×6 ×4 从板面上方拧入。
4. 屏幕排线接 26-pin（CS=22 → spidev1.1）。
5. 开关压进左侧腔，柄对准滑槽，引脚朝内接 pin11 / GND。
