# 外壳（全 3D 打印）

NoKeyOut 的外壳：竖放方盒，**屏幕和 TF 卡在同一面（前脸）**，网口 / USB‑A / USB‑C 全在背面。
外壳是参数化代码生成的——尺寸不写在模型里，而是解析 `web/diy/assets/board/neo3-plus-parts.js`
（仓库里板面真位的唯一出处），所以板子模型一改，开口跟着变。

## 已定的设计

| 决定 | 取值 | 备注 |
|---|---|---|
| 成型方式 | 纯打印，不用亚克力/铜柱 | 端口全在板边，打印开口精度足够 |
| 分件 | 整体壳（含 10.2mm 裙边）+ **滑入式前面板** + 顶盖 | 屏幕直接拧在前面板上，面板从两侧滑槽插入；横缝在 z=10.2 |
| 盖板固定 | 摩擦裙边（单边 0.15mm 过盈） | 无螺丝，拆装快 |
| 屏幕朝向 | 前脸竖直，屏朝 −X | 与 TF 卡同面，端口朝后 |
| 屏幕固定 | 4×M2 直接拧在**前面板**背面（桌面上拧），面板整块 3.4mm 厚 | 无薄壁、无托板；玻璃离外表面 2.2mm |
| 整机 | **57.4 × 56 × 48.5 mm** | 深 × 宽 × 高 |
| 视窗深度 | **2.2 mm** | 面板 3.4，玻璃探进视窗 1.2 |
| 屏幕视窗 | 28.6 方，中心 z 27.8 | 活性区 28.2 |
| TF 槽 | 13.8 × 3.8，z 5.0–9.0 | 与屏下沿留 1.9mm |
| 用户键 K2 | Ø4.2，−Y 侧下部 | 打印加长杆（墙到侧按 1.5mm） |
| MASK K1 | Ø1.8 针孔，−Y 侧下部 | 不做按钮，用针/回形针戳 |
| LED 观察孔 | 前脸裙边上 2 个 Ø2.0 通孔，z 7.05（与 TF 槽同一高度带） | 正对 D1/D2 侧面，孔位取自板面数据 |
| 开关 | 滑槽 **6.5 × 3.4**（中心 x 0，与本体居中），−Y 侧靠上（z 30） | 本体 12×6×6（FBX 实测）；柄宽 4、行程 2.5、FBX 柄位即"关"档；X 向 0.1 过盈压配 + 顶盖/底托；内壁沉台 1mm → 柄露 2.5mm |

## 生成

CadQuery 2.8 装在 **G 盘**（E 盘当时只剩 1.1GB）：

```bash
G:/venvs/nokeyout-case/Scripts/python.exe hardware/case/nokeyout_case.py
```

输出到 `hardware/case/out/`：`base.stl`、`lid.stl`、`button.stl`（打 2 个）、`assembly.step`。

每次运行会打印三道自检，全绿才值得切片：

- **板件干涉**：板 + 30 个元件的高度盒与壳体求交，>1 mm³ 会点名器件；
- **开口自检**：11 个点包含测试，确认视窗 / TF 槽 / 三个端口 / 开关孔 / 按键孔真的切穿，螺柱和壁真的还在；
- **间隙表**：屏幕上沿到顶、屏下沿到 TF 槽、屏幕背面到 26‑pin 排针。

改参数不用动代码：

```bash
... nokeyout_case.py --param base_h=50 --param screen_bottom=13 --param clearance=0.5
```

渲染（Blender 5.2，无头）：

```bash
"G:/blender-5.2.3/blender.exe" -b -P hardware/case/render.py
```

## 打印

| 项 | 建议 |
|---|---|
| 材料 | PETG（贴近 SoC，PLA 长期 60°C 会软） |
| 喷嘴/层高 | 0.4 / 0.2 |
| 壁 / 顶底 | 3 圈 / 4 层 |
| 填充 | 15% 网格即可（受力靠壁） |
| 支撑 | **不需要**：开口全在竖直壁，屏幕螺柱是水平小圆柱 |
| 摆放 | 底壳开口朝上直接放；盖板平面朝下（裙边朝上） |
| 打印量 | 底壳 24.5 cm³、前面板 3.8 cm³、盖 10.1 cm³、加长杆 0.1 cm³ ×1 |

## 装配

1. **桌面上装屏**：屏幕 4 角用 **M2×4 自攻 ×4** 拧进前面板背面螺柱（底孔 Ø1.6，深 2.6；面板平放，螺丝刀竖直）。
2. 主板放上四角螺柱，**M3×5 自攻 ×4**（底孔 Ø2.5，深 4.2；不要用 M3×6，会顶到孔底撑裂螺柱）。
3. 8 根线接到 26‑pin 排针（CS = pin22 → `spidev1.1`，见 `docs/hardware.md`）。
4. 前面板带着屏幕从顶部滑进两侧滑槽，下沿落在裙边顶上。
5. K2 的 Ø4.2 孔塞一根加长杆（帽朝外，杆顶住侧按）；K1 是 Ø1.8 针孔，要用时拿针戳。
6. 开关本体从腔内压进 −Y 侧壁的开关腔（X 向 0.1 过盈，拨柄先对准滑槽），引脚朝内，线接 pin11 / GND(pin9)。
7. 盖板对准裙边压下。

螺丝清单：M3×5 自攻 ×4、M2×5 自攻 ×4、拨动开关 1、加长杆 1（打印件）。

## 打之前必须量的五处

脚本里能改的都做成了参数，但这几个数只有你手上有实物：

| 项 | 当前假设 | 参数 |
|---|---|---|
| 屏幕 PCB 孔位 | ±19.5 / ±13.5（距中心） | `screen_hole_dx` / `screen_hole_dy` |
| 8 针在长边哪一侧 | 必须朝下；居中时 y −8.9…8.9 | 转 180° 或 `base_h` |
| 屏幕模块总厚 | 5.0（PCB 1.6 + 玻璃） | `screen_t` |
| 屏幕孔 | Ø2.2（M2 过孔） | — |
| USB‑A 口在塔身的高度 | 居中 | `PORT_MOUTH` + `PART_HEIGHTS` |
| 拨动开关 | 6mm 面板式 | `switch_hole` |

开口按**插头口**尺寸切（不是元件包围盒），所以量错了最多是口大一点，不会装不进。

## 已知取舍

- **背板开口尺寸取自小游戏模型**：RJ45 15.95 × 16.05（护罩在板下 3mm，口心 +5.0）、
  USB‑A 12.40 × 4.90（插头 12×4.5）、USB‑C 8.60 × 2.70（插头 8.3×2.4，r1.35），都在 `PORT_SHAPE` 里，
  每项是 `(宽, 高, 圆角, 口心相对板顶)`。
- **网口与 USB‑A 仍合并成一个舱**：两份数据的位置互相矛盾——板面 bb 在 Y 上重叠 4.5mm（物理不可能），
  而 FBX 与 bb 的中心又差 1.5–2.6mm。需要实测一个数：两个口沿 Y 的间距，改 `PORT_SHAPE` 里的位置即可分开。
- **屏幕 8 针在 44mm 长边上**：装屏时**必须让针朝下**（z 11.8 那条边）。
  朝上时屏顶到底壳顶只有 1.7mm，4–5mm 的尾线塞不进去 —— 要么把模块转 180°（240×240 方屏，
  改 MADCTL 即可），要么 `--param base_h=50.5` 给顶部加 5mm。
  针朝下时，8 针若居中（y −8.9…8.9）正好避开 2×13 排针所在 y 18.1–24.3；
  但线束仍要从排针端头 1.2mm 的缝隙绕过去，**最好还是把板上 2×13 拆掉**，从通孔焊。
- **屏幕背面到 26‑pin 排针只有 1.12mm**：这是裸 PCB 的间隙，没算尾线/热熔胶。
  拆掉板排针后该约束自然消失。
- **D1/D2 的观察孔开在前脸裙边**（与 TF 槽同高度），不是盖板：它们是板面元件，
  孔轴水平正对 LED 侧面，间距 2.2mm。0402 主发光朝上，从侧面看亮度会低一些；
  要更亮可在孔里塞一小段透明耗材做导光柱，或把孔扩到 Ø3。
- **屏幕托板靠两个 Ø2 销压在前壁上**：销孔按 Ø2.2 切的，FDM 实际会小 0.1–0.15，所以是过渡配合。
  如果打出来偏松，销子上点一滴 CA 胶；要拆的话从上方开口拔托板即可。
- **摩擦裙边会随插拔变松**：长期用可在四角加 M3 自攻（脚本里改 `lip_fit` 为负值前先加柱位）。
